# T7 Parts List (public site)

Public, static copy of the 2025 Ténéré 700 parts list and the Starlink Mini power build guide.

- `data/` cleaned parts data (generated from the private dashboard, never edited by hand)
- `scripts/` build script that turns the data into pages
- `site/` the folder Cloudflare Pages serves
- `drafts/` daily Facebook post drafts (not published)

The private life-dashboard app is not part of this repo.
